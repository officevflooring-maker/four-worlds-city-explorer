How it works

  1. 1Print and cut. Card stock is best, so the pictures don't show through. Print the backs on the other side if you like.
  2. 2Lay the cards face down. Start with one world for young players, and add more as they grow.
  3. 3Find the pairs. Turn over two cards. A pair? Keep it and go again. The most pairs wins.

Questions

Is it like the memory game on this site?

The Memory match game on this site is free to play online, six pairs at a time. The printed game is played at the table, with 42 places and four ways to play.

What age is it for?

Ages 3 and up. Start toddlers with one world of picture cards; readers can match pictures with names.

Can I print more copies?

Yes, for your own home or classroom. Lost a card? Print the page again. Please don't share the file online.
