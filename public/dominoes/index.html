How it works

  1. 1Print and cut. Card stock is best. Keep each set in its own envelope.
  2. 2Pick a set. Picture dominoes for the youngest players, World dominoes for ages 5 and up.
  3. 3Match the ends. Play a tile that matches an open end. The first to play all their tiles wins.

Questions

How can worlds be dots?

A classic set of dominoes has seven numbers, from blank to six. Here each number is a world, so there are 28 tiles, and every two worlds meet on exactly one tile.

What age is it for?

Ages 3 and up for Picture dominoes, where matching ends show the same picture. World dominoes suit ages 5 and up.

Can I print more copies?

Yes, for your own home or classroom. Please don't share the file online.
